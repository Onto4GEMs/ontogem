# OntoGEM Relationships

## Relationships Overview

The following diagram provides a visual overview of the relationships defined between OntoGEM classes.

![OntoGEM Relationships](figures/ontogem-relationships.png)

The table below lists the relationships defined in OntoGEM.

- **Relation** - the preferred label of the relationship.
- **Domain** - the class from which the relationship originates.
- **Range** - the class to which the relationship points.
- **Inverse** - the inverse relationship, when explicitly defined.
- **Cardinality** - indicates the minimum and maximum number of instances that may participate in a relationship. The notation **D..R / R..D** specifies the cardinality from the domain to the range and from the range to the domain, respectively. For example, `1..* / 1` means that each domain instance must be related to at least one range instance, while each range instance must be related to exactly one domain instance.
- **Definition** - describes the meaning of the relationship.
- **Rationale** - explains the motivation for introducing the relationship and, where relevant, the reasoning behind its cardinality or domain and range restrictions.
