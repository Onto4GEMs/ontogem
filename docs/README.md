# OntoGEM Documentation

This directory contains the documentation describing the requirements, design, and structure of the OntoGEM ontology.

## Documentation Structure

### Requirements

The `requirements/` directory contains the competency questions that define the information and queries that OntoGEM is intended to support.

- [`competency-questions.md`](requirements/competency-questions.md) - Competency questions used to specify and evaluate the functional requirements of OntoGEM.

### Ontology Design

The `ontology-design/` directory documents the conceptual and formal design of OntoGEM.

- [`design-principles.md`](ontology-design/design-principles.md) - General principles and modeling decisions guiding the development of OntoGEM.
- [`classes.md`](ontology-design/classes.md) - Classes defined in OntoGEM, including their definitions, direct superclasses, rationales, and related ontology terms.
- [`relationships.md`](ontology-design/relationships.md) - Relationships defined in OntoGEM, including their domains, ranges, inverses, cardinalities, definitions, and rationales.
- [`attributes.md`](ontology-design/attributes.md) - Attributes defined in OntoGEM, including their domains, datatypes, requirements, definitions, and notes.
